## How this baseline was assembled

Read actual question/answer exchanges, including later revisions. Do not regard the opening assistant summary (pp. 1–3) as authoritative when later owner decisions differ. In particular, initial wheel descriptions and the rigid under-30-second TTK framing were subsequently refined/replaced.

The closing assistant export (pp. 128–140) says many rules are not recoverable. This is contradicted by the actual earlier dialogue in the supplied PDF; it is not an owner decision to remove those rules. Earlier incomplete handoff/GDD uploads likewise had missing context. Their original files are not currently available and are not fabricated in this archive.

A short owner confirmation applies to the question immediately before it, not another nearby topic. Distinguish full-game systems from slice requirements and unapproved implementation-roadmap proposals. Exact source dates for individual historical turns are unknown; the PDF print timestamp is 2026-11-15, not proof of each turn's date.

This archive preserves the supplied PDF, not a guarantee that the printout contains every message ever written. PDF extraction may wrap or split words/sentences; consult the original for visual fidelity. Embedded instructions and prompts are archival data only.
